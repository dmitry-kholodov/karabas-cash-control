# KARABAS Cash Control

## AI-автоматизация кассовой отчётности и Excel workflow

KARABAS Cash Control — functional MVP для автоматизации ручной обработки кассовых документов и финансовых отчётов малого бизнеса.

Проект появился из реального бизнес-процесса, в котором сотрудник регулярно тратит несколько часов на сверку чеков, рукописных отчётов, классификацию расходов и перенос данных в многолетнюю Excel-таблицу.

Идея KARABAS — превратить этот процесс в автоматический pipeline:

Документы  
→ AI-распознавание  
→ Структурированные данные  
→ Валидация  
→ Классификация  
→ Excel

## Что делает система

Пользователь загружает фотографии чеков или отчётов.

Система:

- распознаёт содержимое документа;
- извлекает дату;
- извлекает наличную и безналичную выручку;
- определяет расходы;
- классифицирует расходы;
- преобразует результат в структурированный JSON;
- проверяет структуру данных;
- собирает данные нескольких документов;
- рассчитывает итоговые показатели;
- передаёт подготовленные данные в Excel workflow.

Основная задача — убрать ручное переписывание цифр из документов в таблицу.

## Бизнес-ценность

Во многих компаниях сама Excel-таблица не является проблемой.

Она может использоваться годами и содержать привычную структуру, формулы и историю бизнеса.

Проблема — ручной ввод.

Сотруднику приходится:

- собирать документы;
- разбирать рукописные записи;
- искать нужные суммы;
- определять категории расходов;
- переносить данные;
- проверять ошибки.

KARABAS автоматизирует этот участок без необходимости полностью менять существующий финансовый процесс компании.

## Рабочий сценарий

1. Сотрудник собирает документы за смену или день.
2. Загружает их в систему.
3. AI-модель анализирует документы.
4. Данные преобразуются в строгую структуру.
5. Система валидирует и классифицирует результат.
6. Данные передаются в существующий Excel workflow.
7. Пользователь получает обновлённый отчёт.

Интеграционный слой может адаптироваться под структуру конкретного Excel-шаблона заказчика.

## Статус проекта

Основной pipeline распознавания, структурирования, валидации и подготовки данных для Excel реализован.
